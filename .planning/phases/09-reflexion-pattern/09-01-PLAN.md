    创建 `@Component` 实现 `AgentPattern`：`id()="reflexion"`、`displayName()="Reflexion 反思迭代"`、`description()="犯错后自我纠错"`。

    **构造注入（per D-01）:** 仅 `ChatClient.Builder chatClientBuilder` + `ObjectMapper objectMapper`。**不注入 ToolRegistry**（Reflexion 为纯 LLM 推理，不需要外部工具）。使用默认模型（application.yml 已配置 deepseek-reasoner，不额外指定模型）。

    **常量（private static final）：**
    - `MAX_REFLECTIONS = 2`（硬上限，per D-04）
    - `PASS_THRESHOLD = 8`（评估通过阈值，>=8 即通过，per UI-SPEC 评分语义三元组）
    - `EPSILON = 1`（改进幅度阈值，per D-04 Claude's Discretion）
    - `DEFAULT_SCORE = 5`（评分解析失败兜底中位分，per RESEARCH.md Pitfall 2）

    **Prompt 模板（3 个独立 system prompt，per D-02 + Claude's Discretion）：**

    `GENERATOR_PROMPT`（第一轮，无反思历史）：
    ```
    你是一个 Reflexion Agent 的 Generator。请回答以下问题，尽可能给出完整、准确的答案。
    问题: {question}
    ```

    `GENERATOR_WITH_REFLECTION_PROMPT`（后续轮次，含反思历史，per Claude's Discretion -- 反思内容注入为 user message 而非 system prompt）：
    ```
    你是一个 Reflexion Agent 的 Generator。请回答以下问题。
    问题: {question}
    你之前的回答以及评估反馈如下：
    上一轮答案: {prevAnswer}
    评估分数: {prevScore}/10
    评估反馈: {prevFeedback}
    反思改进方向: {reflection}
    请基于以上反馈，改进你的答案，给出更准确、更完整的回答。
    ```
    注意：{prevAnswer}/{prevScore}/{prevFeedback}/{reflection} 在 prompt 模板中作为占位符，构建时替换为实际值。Evaluator 和 Reflector 的反馈内容通过 `String.replace()` 注入 prompt 字符串。

    `EVALUATOR_PROMPT`（LLM-as-judge，per D-02 + RESEARCH.md Pitfall 2 缓解方案 -- 要求结构化 JSON 输出）：
    ```
    你是一个 Reflexion Agent 的 Evaluator（LLM-as-judge）。
    请评估以下答案的质量。
    问题: {question}
    答案: {answer}
    请从完整性、准确性、逻辑性三个维度评估，输出一个 1-10 的整数评分和反馈意见。
    请严格按照以下 JSON 格式输出，不要包含任何额外的文字或 markdown 包裹：
    {"score": <1-10 整数>,"feedback": "<详细的反馈意见，指出优点和不足>"}
    输出 ONLY 上述 JSON 对象。
    ```

    `REFLECTOR_PROMPT`（per Claude's Discretion -- 要求具体可操作的改进方向，而非笼统承认错误）：
    ```
    你是一个 Reflexion Agent 的 Reflector。
    请根据评估反馈，生成具体的反思和改进方向。
    问题: {question}
    当前答案: {answer}
    评估分数: {score}/10
    评估反馈: {feedback}
    请输出 2-3 条具体的、可操作的改进方向。
    每条改进方向应该明确指出"下一轮应该具体改变什么"，而不是笼统地承认错误。
    请严格按照以下 JSON 格式输出：
    {"reflection": "<反思内容，包含具体的改进方向...>"}
    ```

    **辅助方法：**

    `extractJson(String raw)` -- 与 TreeOfThoughtsAgentPattern 相同：strip ```json/``` 标记，取第一个 { 到最后一个 }。返回 null 表示无有效 JSON。

    `parseScoreSafely(String raw)` -- 与 ToT 的 parseScoreSafely 相同模式，但额外添加 JSON 提取策略（因为 Evaluator prompt 要求 JSON 输出）。策略链：
    1. raw 为 null/blank -> 返回 DEFAULT_SCORE=5
    2. 提取 JSON，取 `{"score": N, ...}` 中的 score 值 -> clamp
    3. 正则 `评分[:：]\s*(\d+)` 匹配 -> clamp
    4. 正则 `(\d+)\s*/\s*10` 匹配（如 "8/10"）-> clamp
    5. 提取第一个独立数字 1-10 -> clamp
    6. 关键词匹配（优秀/excellent->9，好/good->7，一般/average->5，差/poor->3）
    7. 兜底返回 5
    `clamp(score)` = Math.max(1, Math.min(10, score))

    `extractFeedback(String raw)` -- 从 Evaluator JSON 输出中提取 feedback 字段。策略链：
    1. 提取 JSON，取 `{"feedback": "...", ...}` 中的 feedback 值
    2. JSON 解析失败 -> 返回 raw.trim()（原始文本降级）

    `extractReflection(String raw)` -- 从 Reflector JSON 输出中提取 reflection 字段。策略链：
    1. 提取 JSON，取 `{"reflection": "...", ...}` 中的 reflection 值
    2. JSON 解析失败 -> 返回 raw.trim()（原始文本降级）

    `selectBestAnswer(List<RoundResult> rounds)` -- best-of-N 策略（per Claude's Discretion）：取最高分轮次的 answer。分数相同时取最后一轮。

    `RoundResult` -- 内部 record，用于追踪每轮结果：
    ```java
    private record RoundResult(int round, String answer, int score, String feedback, String reflection) {}
    ```

    **execute(AgentContext ctx) 实现（Flux.create sink，try-catch 环绕整体，per D-04 同步顺序执行）：**

    ```
    1. 初始化: List<RoundResult> rounds = new ArrayList<>()
       int prevScore = 0 (用于 epsilon 比较)
       int round = 1

    2. Round 1 Generator:
       answer = chatClientBuilder.defaultSystem(GENERATOR_PROMPT.replace("{question}", ctx.question())).build()
           .prompt().user(u -> u.text(ctx.question())).call().content()
       sink.next(new ReflexionAttemptEvent(Instant.now(), 1, answer))

    3. Round 1 Evaluator:
       evalRaw = chatClientBuilder.defaultSystem(EVALUATOR_PROMPT
           .replace("{question}", ctx.question()).replace("{answer}", answer)).build()
           .prompt().user(u -> u.text("问题: " + ctx.question() + "\n答案: " + answer)).call().content()
       score = parseScoreSafely(evalRaw)
       feedback = extractFeedback(evalRaw)
       sink.next(new ReflexionEvaluateEvent(Instant.now(), 1, score, feedback))
       rounds.add(new RoundResult(1, answer, score, feedback, ""))

    4. 检查是否通过:
       if (score >= PASS_THRESHOLD): goto FINALIZE (epsilon 无意义，高分不需要继续)

    5. Round 1 Reflector (if score < PASS_THRESHOLD && MAX_REFLECTIONS >= 1):
       reflectionRaw = chatClientBuilder.defaultSystem(REFLECTOR_PROMPT
           .replace("{question}", ctx.question()).replace("{answer}", answer)
           .replace("{score}", String.valueOf(score)).replace("{feedback}", feedback)).build()
           .prompt().user(u -> u.text("问题: " + ctx.question() + "\n答案: " + answer)).call().content()
       reflection = extractReflection(reflectionRaw)
       sink.next(new ReflexionReflectEvent(Instant.now(), 1, reflection))
       rounds.get(rounds.size()-1) = new RoundResult(1, answer, score, feedback, reflection)
       // 注意：Java record 不可变，这里用 rounds.set() 替换

    6. Round 2 Generator (if MAX_REFLECTIONS >= 2):
       prevScore = score
       prevRound = rounds.get(0)
       improvedAnswer = chatClientBuilder.defaultSystem(GENERATOR_WITH_REFLECTION_PROMPT
           .replace("{question}", ctx.question())
           .replace("{prevAnswer}", prevRound.answer())
           .replace("{prevScore}", String.valueOf(prevRound.score()))
           .replace("{prevFeedback}", prevRound.feedback())
           .replace("{reflection}", prevRound.reflection())).build()
           .prompt().user(u -> u.text("问题: " + ctx.question())).call().content()
       sink.next(new ReflexionAttemptEvent(Instant.now(), 2, improvedAnswer))

    7. Round 2 Evaluator:
       evalRaw2 = ...
       score2 = parseScoreSafely(evalRaw2)
       feedback2 = extractFeedback(evalRaw2)
       sink.next(new ReflexionEvaluateEvent(Instant.now(), 2, score2, feedback2))
       rounds.add(new RoundResult(2, improvedAnswer, score2, feedback2, ""))

    8. Epsilon 检查 (per D-04 + RESEARCH.md Pitfall 4 缓解 -- 仅当 score2 < PASS_THRESHOLD 时才检查 epsilon):
       if (score2 >= PASS_THRESHOLD): goto FINALIZE
       // epsilon 检查：仅当分数未通过且变化幅度 < EPSILON 时提前停止
       if (Math.abs(score2 - prevScore) < EPSILON):
         // 触发 epsilon 提前停止 -- 不发射 Reflector，直接选最优答案
         // 注意：这里不发射额外的 ErrorEvent，而是正常选择最佳答案
         goto FINALIZE

    9. FINALIZE:
       bestAnswer = selectBestAnswer(rounds)
       sink.next(new FinalAnswerEvent(Instant.now(), bestAnswer))
       sink.complete()

    10. catch (Exception ex):
        sink.next(new ErrorEvent(Instant.now(), "Reflexion 模式执行异常: " + ex.getMessage()))
        sink.complete()
    ```

    **实现要点：**
    - 使用 `tools.jackson.databind.ObjectMapper` / `tools.jackson.databind.JsonNode` 导入（匹配现有 pattern 约定，NOT com.fasterxml.jackson）
    - `Flux.create` + `FluxSink` 模式（匹配 ToT/ReAct/Self-Ask/Plan-Execute），不用 Sinks.Many
    - 每次 LLM 调用均 `.call().content()`（需完整 JSON/响应，非流式）-- 所有 Generator/Evaluator/Reflector 调用均为 blocking 调用
    - 评分/反馈/反思解析永不抛异常中断流 -- parseScoreSafely/extractFeedback/extractReflection 内部兜底
    - 最多 2 轮 Generator + 2 轮 Evaluator + 1 轮 Reflector = 约 5 次 LLM 调用，教学演示节奏合理
    - 若第 1 轮评估已通过（score >= PASS_THRESHOLD），不发射 Reflector 事件，也不进行第 2 轮
    - 若第 2 轮评估分数与第 1 轮差 < EPSILON 且未通过，停止循环（不发射 Reflector 事件）
    - `selectBestAnswer` 从 rounds 列表中选最高分轮次的答案
