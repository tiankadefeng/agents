  <action>
    创建 `@Component` 实现 `AgentPattern`：`id()="tot"`、`displayName()="Tree of Thoughts 树状思维"`、`description()="多分支探索与评估，贪心剪枝选最优路径"`。

    **构造注入（per D-04）:** 仅 `ChatClient.Builder chatClientBuilder` + `ObjectMapper objectMapper`。**不注入 ToolRegistry**（ToT 为纯 LLM 推理，探索类问题不需要工具）。不改 application.yml（默认模型即 deepseek-chat）。

    **常量（private static final，本阶段锁定，v2 才做 UI 可调）：**
    - `BRANCHING = 3`（每存活节点生成分支数）
    - `DEPTH = 3`（扩展层数，level 0/1/2）
    - `TOP_K = 2`（每层保留节点数）
    - `MAX_TOTAL_NODES = 50`（总节点数保险丝）
    - `DEFAULT_SCORE = 5`（评分解析失败兜底中位分）
    - `GENERATE_SYSTEM_PROMPT` -- 分支生成器（RESEARCH.md §3.1）：给定原始问题 + 当前推理路径，生成 3 个不同后续思考方向，严格输出 JSON `{"branches": ["分支1...", "分支2...", "分支3..."]}`，分支间有明显差异，禁止 markdown 包裹。
    - `EVALUATE_SYSTEM_PROMPT` -- 评估器（RESEARCH.md §3.2）：从逻辑合理性/相关性/解决潜力三维度评估推理思路，输出 1-10 整数评分（10=优秀，7-9=很好，4-6=一般，1-3=较差），只输出整数。
    - `SUMMARIZE_SYSTEM_PROMPT` -- 汇总器（RESEARCH.md §3.3）：给定原始问题 + 最优推理路径（完整思路链），给出清晰完整的最终答案。

    **私有数据结构:**
    - `private record TotNode(int id, int level, Integer parentId, String thought, int score) {}` -- 评分先算出再构造 record，无需可变 score。
    - `extractJson(String raw)` -- 与 PlanAndExecuteAgentPattern 相同：strip ```json/``` 标记，取第一个 { 到最后一个 }。

    **评分容错解析 `parseScoreSafely(String raw)`（per D-02，永不抛异常）：**
    1. raw 为 null/blank -> 返回 DEFAULT_SCORE=5
    2. 正则 `评分[:：]\s*(\d+)` 匹配 -> clamp
    3. 正则 `(\d+)\s*/\s*10` 匹配（如 "8/10"）-> clamp
    4. 提取第一个独立数字 1-10 -> clamp
    5. 关键词匹配（优秀/excellent->9，好/good->7，一般/average->5，差/poor->3）
    6. 兜底返回 5
    - `clamp(score)` = Math.max(1, Math.min(10, score))

    **分支解析 `parseBranches(String raw)`:** extractJson + objectMapper.readTree -> 取 "branches" 数组各元素 asText()。解析失败或数组为空时降级：将整个原始文本作为单一分支返回（至少 1 个分支，RESEARCH.md §11 风险缓解）。

    **execute(AgentContext ctx) 实现（Flux.create sink，try-catch 环绕整体）：**

    ```
    1. 根节点: TotNode root = new TotNode(nodeSeq++, -1, null, ctx.question(), 0)
       allNodes.put(root.id(), root)   // Map<Integer, TotNode>，用于回溯
       sink.next(new TotNodeEvent(now, -1, root.id(), root.thought(), 0, null))
       aliveNodes = List.of(root)      // 当前层存活节点
       totalNodes = 1

    2. BFS 主循环 (per D-01): for (int level = 0; level < DEPTH; level++):
       // ===== EXPAND + SCORE =====
       nextLevel = new ArrayList<TotNode>()
       for (TotNode parent : aliveNodes):
         if (totalNodes >= MAX_TOTAL_NODES): 触发保险丝（见步骤 3），break 外层循环
         raw = chatClientBuilder.defaultSystem(GENERATE_SYSTEM_PROMPT).build()
             .prompt().user(u -> u.text("问题: " + ctx.question()
                 + "\n当前推理路径: " + parent.thought()))
             .call().content()     // call() 非 stream() -- 需完整 JSON 响应
         branches = parseBranches(raw)
         for (String branch : branches):
           if (totalNodes >= MAX_TOTAL_NODES): break
           // SCORE (per D-02): 每节点独立评估调用
           scoreRaw = chatClientBuilder.defaultSystem(EVALUATE_SYSTEM_PROMPT).build()
               .prompt().user(u -> u.text("问题: " + ctx.question()
                   + "\n推理思路: " + branch))
               .call().content()
           int score = parseScoreSafely(scoreRaw)
           TotNode node = new TotNode(nodeSeq++, level, parent.id(), branch, score)
           allNodes.put(node.id(), node)
           sink.next(new TotNodeEvent(Instant.now(), level, node.id(), node.thought(), score, node.parentId()))
           nextLevel.add(node)
           totalNodes++

       if (nextLevel.isEmpty()):
         // 该层全部分支生成失败 -> 降级
         sink.next(new ErrorEvent(now, "所有分支均已被剪枝，将使用当前评分最高的节点生成答案。"))
         break   // 用当前 aliveNodes（上一层存活节点）回溯最优路径

       // ===== PRUNE (per SC#3): 最后一层（level == DEPTH-1）不剪枝 =====
       if (level < DEPTH - 1):
         nextLevel.sort(Comparator.comparingInt(TotNode::score).reversed())
         if (nextLevel.size() > TOP_K):
           prunedIds = nextLevel.subList(TOP_K, size) 的 id 列表
           sink.next(new TotPruneEvent(now, level, prunedIds, "评分低于 top-K=" + TOP_K + " 阈值"))
           aliveNodes = new ArrayList<>(nextLevel.subList(0, TOP_K))
         else:
           aliveNodes = nextLevel
       else:
         aliveNodes = nextLevel   // 叶子层全部保留

    3. 保险丝 (RESEARCH.md §1.4): totalNodes >= MAX_TOTAL_NODES 时不直接中断：
       sink.next(new ErrorEvent(now, "Tree of Thoughts 节点数已达上限 (" + MAX_TOTAL_NODES
           + ")，将从已探索路径中生成答案。"))
       break -- 用已生成的节点继续最优路径回溯（尽力而为答案，非错误终止）

    4. SELECT (per SC#4): 最优路径回溯
       best = aliveNodes.stream().max(Comparator.comparingInt(TotNode::score)).orElse(root)
       // 注意：只在存活节点中选最高分，被剪枝节点不参与（SC#4 "从存活分支中选出最优路径"）
       path = new ArrayList<TotNode>()
       current = best
       while (current != null):
         path.add(current)
         current = current.parentId() != null ? allNodes.get(current.parentId()) : null
       Collections.reverse(path)   // 根 -> 叶子
       pathText = 拼接为 "第 1 步: {root.thought}\n第 2 步: {level0.thought}\n..." 格式

    5. SUMMARIZE:
       summary = chatClientBuilder.defaultSystem(SUMMARIZE_SYSTEM_PROMPT).build()
           .prompt().user(u -> u.text("原始问题: " + ctx.question()
               + "\n\n最优推理路径:\n" + pathText))
           .call().content()
       if (summary != null && !summary.isBlank()):
         sink.next(new FinalAnswerEvent(Instant.now(), summary))
       else:
         sink.next(new ErrorEvent(Instant.now(), "Tree of Thoughts 未能生成最终答案，请重试或更换问题。"))
       sink.complete()

    6. catch (Exception ex):
       sink.next(new ErrorEvent(Instant.now(), "Tree of Thoughts 模式执行异常: " + ex.getMessage()))
       sink.complete()
    ```

    **实现要点:**
    - 使用 `tools.jackson.databind.ObjectMapper` / `tools.jackson.databind.JsonNode` 导入（匹配现有 pattern 约定，NOT com.fasterxml.jackson）
    - `Flux.create` + `FluxSink` 模式（匹配 ReAct/Self-Ask/Plan-Execute），不用 Sinks.Many
    - 每次 LLM 调用均 `.call().content()`（需完整 JSON/整数响应，非流式）

    - nodeSeq 从 0 开始（根节点 id=0），单调递增保证全局唯一
    - 约 19-32 次 LLM 调用/次执行（生成 7 次 + 评估 13-19 次 + 汇总 1 次），教学演示可接受
